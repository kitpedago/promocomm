# Écrans de l'application WinDev (référence UI)

Analyse des 17 captures de [migration_windev/](../migration_windev/), faite le 2026-07-04.
Sert de référence pour reconstruire les écrans ; croiser avec [modele-legacy.md](modele-legacy.md)
et [schema-cible.md](schema-cible.md). Le code source WinDev sera exposé sur un dépôt GitHub (à venir).

## Pattern d'interface omniprésent

1. **Liste maître à gauche** (opérations ou SCCV) : recherche « Contient » (min. 3 caractères,
   sans accent), compteur (« 97 opérations »), panneau repliable (`«`).
2. Cases **« Inclure les Masquer commercial/comptable/promo »** : c'est l'usage réel des flags
   `masquer_*` de `operation` — chaque module filtre sur le sien (Commercialisation 56 ops,
   SAV 68, Compta 97).
3. **Détail à droite par tranche** : sélecteur « Tranche (N). Filtrer sur : LIBELLÉ (Coll. : X
   dont PSLA n, dont BRS n, Indiv. : …) » — le récap vient des compteurs de `tranche`.
4. **Sections en accordéon vertical** (bandeaux pleine largeur, section active en jaune) et
   sous-onglets horizontaux ; tables avec tri/filtre/loupe par colonne, bandeau d'en-tête à
   groupes multi-niveaux colorés, ligne Total, boutons Nouveau/Modifier/Supprimer à droite.

## Détails notables pour la ré-implémentation

- Le sélecteur de tranche et son récap (« Coll. : 18 dont PSLA 8… ») sont le fil conducteur de
  presque tous les modules → composant réutilisable à prévoir.
- « Lot courant » d'un acquéreur = sa commercialisation non annulée la plus récente (le legacy
  le cachait dans `curIDLot`/`DescriptionLotCourant`, non repris → à calculer par jointure).
- La grille de facturation confirme le piège `tGrilleFacturation.IDStadeAvancement` →
  `tListeAvancement` (les lignes sont des stades de la nomenclature : ESQ, DPC, AO…).
- `tSGA.Budget`/commentaires contiennent du **HTML brut** (`<div>C3 AL</div>`) — à assainir
  (défaut ajouté au backlog source).
- « Motif annulation » est une liste paramétrable dans FEN_Param alors que
  `tCommercialisation.MotifAnnulation` est du texte libre — incohérence source à trancher.
- La liste `Commune` (583 entrées) existe mais `tOperation.Commune` est du texte libre.
- Fonctions transverses à prévoir un jour : exports Excel (Planning Excel, Exporter),
  impression, envois de mails SAV, import Air-Bat, alertes stades.
